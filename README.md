# Optimus Booth Activation

Concept: Party Favor Photo - Tesla dealership photo booth activation run by a Humanoid Robot

### Vision
A brand experience where a Tesla Optimus humanoid robot serves as the photo booth attendant at Tesla dealerships. The robot becomes both the attraction and the service - people line up for a photo with the robot THAT is running the photo booth.

### Hypothesis

The robot is the show. The photo booth is the deliverable. Together they create a selling experience for both Tesla and Party Favor Photo.
